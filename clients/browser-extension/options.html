WebAgent Browser Connector

This extension runs commands from your WebAgent server in this browser, in your own logged-in session. You can watch every action and pause anytime from the toolbar icon.

Use wss:// / https:// for a remote server. http(s) is auto-converted to ws(s).
Required unless your server is in open (single-user) access mode. To get one: open the WebAgent Browser page, click the plug icon (“Pair extension”), and copy the Server URL and Token shown there into these two fields. Leave blank only in open mode.
