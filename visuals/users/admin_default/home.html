AI Agent Platform

webAgent

A tool-calling AI agent with memory, persistent sessions, and a live page workspace — running locally or on the cloud.

⚡ Core Features

💬

Persistent Chat

Conversations persist across sessions. The agent remembers context from prior turns automatically.

🧠

Hybrid Memory

Keyword + vector search surfaces relevant past knowledge before every response.

🔧

Dynamic Tools

Tools are created on demand and stored in the DB. Bootstrap discovery runs from turn 1.

🎨

AutoAgent Pages

Build and maintain custom HTML pages — dashboards, notes, visuals — right in this tab.

📎

File Attachments

Upload images, audio, video, and documents. The agent reads and processes them inline.

🗄️

Dual Storage

Switch between local SQLite and Supabase cloud from the settings toggle at any time.

🚀 Getting Started

1

Install dependencies

Create a virtual environment and run pip install -r requirements.txt

2

Configure your API key

Copy .env.example to .env and set OPENROUTER_API_KEY. Or use the ⚙️ Settings modal in the UI.

3

Start the server

Run uvicorn app.main:app --reload --port 8080 or double-click webAgent.bat on Windows.

4

Open the UI & chat

Go to http://localhost:8080. Your first message seeds your agent context automatically.

✨ Tips

→Use AutoAgent pages (this tab) to build persistent custom interfaces. Click + to add a new page.
→Each page has its own dedicated agent — the home agent knows about webAgent, a dashboard agent knows about your dashboards.
→The agent discovers tools automatically via list_tools — no need to tell it what's available.
→Toggle Local / Cloud storage in the top bar to switch SQLite ↔ Supabase without losing data.
→Say "add a section about X" or "redesign the layout" and the agent will update this page directly.
