GitHub Token —
How to create a GitHub token →

Classic token:

  1. Go to github.com/settings/tokens
  2. Click Generate new token (classic)
  3. Give it a name (e.g. "webAgent")
  4. Select scope: repo (full control)
  5. Click Generate token and copy it

Fine-grained token:

  1. Go to github.com/settings/tokens
  2. Click Generate new token (fine-grained)
  3. Select this repository only
  4. Permissions → Contents: Read and write
  5. Click Generate token and copy it

Paste the token above and click Save. It's stored locally in provider.json.

Agent Tools

Privileged capabilities for editing the running app. Enable here, then turn on per agent from the agent's Abilities tab.

Codebase Admin
Lets the agent read, write, edit, delete files, and run shell commands on the host.
Disabled
Codebase Admin is available on the agent's Abilities tab. Only agents that turn it on receive the source tools.
Enabling exposes Codebase Admin as a toggle to agent admins. Destructive operations still require the user to confirm at chat time.
Create Tools
Lets the agent define new tools in the database. Useful for cloud / ephemeral deployments where the codebase resets but the tools table persists.
Disabled
Create Tools is available on the agent's Abilities tab. The agent's create_tool handler writes to the tools table.
Enabling exposes Create Tools as a toggle to agent admins. Tool code is sandboxed by a safety scanner that blocks filesystem and shell imports.
Automation
Exposes the per-agent Automation tab — scheduled tasks and event-triggered jobs that can call integrations.
Disabled
Automation is available on each agent's Abilities tab. Agent admins must toggle it on per agent before the Automation tab appears.
Warning: Disabling will permanently delete every agent's scheduled tasks and event subscriptions.
Enabling exposes Automation as a per-agent toggle. Agents with the toggle off see no Automation tab.
